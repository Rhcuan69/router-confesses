`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — an original one-line excuse from a home Wi-Fi router for dropping the connection at the exact moment a movie reaches its climax. The output is deterministic: every run produces byte-identical output.

> The villain was mid-monologue when I realized the only plot twist this house was getting tonight was me.

## Run it

```sh
python3 main.py
```
